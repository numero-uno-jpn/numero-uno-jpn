# 梅谷 直亨 / Naoyuki Umetani, MD, PhD

東京の消化器外科医です。30 年あまり消化器外科の手術とがん診療 (化学療法・緩和医療を含む) に携わり、東京大学大学院と米国 John Wayne Cancer Institute でがんの分子生物学を研究してきました (医学博士)。医学生のころから医療用ソフトウェアの開発もしています。

A gastrointestinal surgeon in Tokyo (MD, PhD) with three decades of surgical and oncology practice and a background in cancer research. I have also been writing medical software since medical school.

### 公開しているもの / Projects

- **[休薬情報データベース (kyuyaku-data)](https://github.com/numero-uno-jpn/kyuyaku-data)**: 手術・処置や造影 CT の前に、どの薬を何日前から休薬するかを、学会ガイドラインや添付文書などの一次資料に基づいて整理したオープンデータ ([参照アプリ](https://numero-uno-jpn.github.io/kyuyaku-data/))
- **[研究の系譜マップ](https://numero-uno-jpn.github.io/research-map/)**: 2006 年に報告した血中遊離 DNA の integrity によるがん診断が、その後どのような研究につながったかを俯瞰するページ

### 背景 / Background

- 日本外科学会・日本消化器外科学会・日本大腸肛門病学会 専門医・指導医
- 英文論文 (PubMed 収載) 45 編。血中遊離 DNA、DNA メチル化、大腸がんの発生などを研究
- 周術期の薬物療法と安全に関わる仕事として、抗血栓療法中の患者の緊急消化管手術の解析 ([BMC Gastroenterol 2021](https://pubmed.ncbi.nlm.nih.gov/34418977/)) や、薬剤師と連携したがん化学療法時の B 型肝炎再活性化予防の仕組みづくり (医療薬学 2022、責任著者)
- 医学生時代に、臨床統計解析ソフト FISHER と医学統計グラフ作成ソフト ESCHER (中山書店) の開発に参加
